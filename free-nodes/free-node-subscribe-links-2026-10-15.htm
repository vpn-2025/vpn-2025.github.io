添加服务器：构建连接的基石

首次打开V2RayNG，主界面会呈现一个空白的服务器列表。点击界面上的“+”按钮，便会展开添加配置的选项。在这里，用户需要输入从服务器提供商处获取的关键信息。地址是服务器的IP或域名，端口是连接服务器的通道，用户ID则是识别用户身份的独特凭证。对于不同的协议，所需的信息可能有所不同。例如，使用VMess协议时，除了上述基本信息外，可能还需要设置alterId（额外ID）等参数。务必确保每一项信息都准确无误，任何一个小错误都可能导致连接失败。在输入信息时，V2RayNG提供了清晰的字段提示，用户只需对照服务器提供商给出的配置信息逐一填写即可。

V2RayNG的智能分流功能是其一大亮点。在“设置”菜单中，用户可以找到“分流规则”选项。启用分流后，用户可以选择预设的规则，如“绕过局域网及大陆地址”，这意味着访问国内网站时将直接连接，不经过代理，从而保证了国内网站的访问速度；而访问国外网站时则自动通过代理，实现无缝切换。用户还可以根据个人需求，自定义添加特定的域名或IP规则，实现更精细化的流量控制。这种智能分流机制，让网络访问既快又稳，极大地提升了使用体验。

FAQ

PassWall2 在路由器上使用 TUN 模式会有什么影响？
启用 TUN 模式会拦截并转发路由器上全部或选定流量，这会增加路由器 CPU 与内存负担，可能影响路由器其他服务表现。建议在性能足够的设备上启用，或仅对特定设备/端口进行分流。
SSR 协议和混淆选择如何影响稳定性？
根据网络封锁情况选择合适协议和混淆方式，如 tls1.2_ticket_auth 模拟 HTTPS 流量。合理组合可提升抗封锁能力和连接稳定性，确保节点长期可用，优化网络访问。
使用 Reality 协议后，客户端与服务端的密钥如何管理？
Reality 使用公私钥对进行认证，应生成唯一的公私钥对并妥善保存私钥，公钥可部署在服务端配置中。避免在多个服务共享同一密钥，定期轮换密钥并通过安全通道传输公钥以防泄露。
Clash 策略组如何实现节点优先级切换？
用户可以在 Clash 策略组中设置节点优先级，结合规则文件自动选择延迟低、稳定性高的节点处理流量。优化网页浏览、视频播放和游戏访问速度，提高整体网络效率。
V2Ray 的 gRPC 传输方式有哪些优势？
V2Ray gRPC 传输支持多路复用和长连接，减少握手次数。它对高延迟网络和移动网络非常友好，同时可通过 TLS 加密保护数据，提高隐蔽性和稳定性。
V2Ray 的 WebSocket + TLS 配置有哪些优势？
WebSocket + TLS 可以伪装成普通 HTTPS 流量，增强抗封锁能力。适合高封锁环境，结合域名伪装和策略组，可实现高安全性和稳定的网络访问体验。
Sing-box 精确端口分流如何提升游戏连接？
Sing-box 可按端口设置流量分流规则，将游戏流量分配到低延迟节点。结合策略组使用，可保证游戏连接稳定，减少延迟和掉线，提高流畅度和网络体验。
如何备份 Clash 配置文件？
Clash 的配置文件通常位于程序目录或配置文件夹中（如 Windows 下的 .config/clash）。用户可直接复制该 YAML 文件以备份，也可将订阅链接保存，便于后续恢复或在其他设备上同步使用。
Hiddify Next 的多用户限速功能如何使用？
Hiddify Next 支持在管理面板中为每个用户设置带宽上限。管理员可以按需分配速率或流量配额，防止单一用户占用过多资源，从而保持整体网络稳定。
如何使用 Docker 部署 sing-box 或 v2ray？
选择官方或社区维护的 Docker 镜像，编写 docker-compose.yml 指定配置文件挂载、网络模式与端口映射。使用容器管理可以隔离运行环境、便于日志采集并与反向代理（如 Nginx）协同工作。
